Privacy policy

Last updated: November 25, 2026

Ledger is a personal tool used by one household. It is not a public service.

What it accesses

  • One dedicated Gmail inbox that only receives forwarded bank alert emails, using the read-only Gmail permission (gmail.readonly).
  • It never sends, deletes, labels or modifies email, and never accesses any other mailbox.

What it stores

  • Transaction amount, date, merchant and the last 4 digits of the card, stored on a private home server.
  • Full card numbers are masked and never stored.

Sharing

No data is sold, shared with third parties, or used for advertising. Data obtained through Google APIs is used only to provide this tool's budgeting function, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Removal

Access can be revoked at any time at myaccount.google.com/permissions.
